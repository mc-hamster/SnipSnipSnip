# App Store artwork

Versioned campaigns retain original artwork, reviewed app captures, rendering
scripts, and submission assets. The current campaign is
[SnipSnipSnip 1.2.0](SnipSnipSnip%20v1.2.0/README.md).

## Renderer dependencies

Use Node.js 20.9 or later. From the repository root, install the shared, pinned
dependencies with:

```sh
npm ci --prefix 'assets/App Store'
```

The shared installation supports the versioned renderers without vendoring
dependencies inside a previous campaign. Commit `package.json` and
`package-lock.json`; keep installed `node_modules` out of Git. The 1.2.0 preview
renderer also needs `ffmpeg`, and its validator needs `ffprobe`.

## Generated files

Keep submission ZIPs and checksum files under the ignored `build/` directory.
The individual assets are tracked so packaging does not duplicate them in Git.
Preview backgrounds under `review/preview-render/` are generated by the preview
renderer and ignored. Compiled filming utilities under `filming/bin/` are local
build products, not repository source. Duplicate copies with a ` 2`
suffix are not campaign inputs.
