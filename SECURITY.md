# Security Policy

SnipSnipSnip handles screenshots, recordings, clipboard history, OCR text, annotations, and optional UI Map metadata. Reports involving unintended disclosure, unsafe redaction, permission handling, local data exposure, export metadata, or automation boundaries are treated as security-sensitive.

## Report Privately

Please use the [Oontz support form](https://www.oontz.com/contact/) and clearly label the message **SnipSnipSnip security report**. Do not open a public GitHub issue until the report has been reviewed.

Include the affected SnipSnipSnip edition and version, macOS version, a concise reproduction, and the expected impact. Do not send real secrets or private captures. Use a minimal synthetic example whenever possible.

You should receive an acknowledgement before any public disclosure or detailed public discussion.
